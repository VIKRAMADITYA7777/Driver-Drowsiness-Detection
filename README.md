# Intelligent Driver Drowsiness Detection

Production-grade project for Driver Drowsiness Detection using Deep Learning, Explainable AI and Real-Time Alerts.

## Objective
- Real-time webcam monitoring
- Eye closure, blink, yawn detection
- EAR, MAR, PERCLOS metrics
- CNN + LSTM prediction
- Explainable AI (Grad-CAM, LIME)
- Analytics dashboard and historical reports

## Tech Stack
- Frontend: Angular 19, TypeScript, Bootstrap 5, Angular Material
- Backend: Python 3.10, FastAPI, OpenCV, MediaPipe, TensorFlow/Keras
- DB: SQLite (SQLAlchemy)
