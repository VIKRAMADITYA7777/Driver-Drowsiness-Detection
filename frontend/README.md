# Frontend (Angular)

Scaffold for the Angular 19 frontend. This folder contains a minimal app skeleton, theme files and instructions to install dependencies.

To create a full Angular app using the Angular CLI locally (recommended):

```powershell
npx @angular/cli@19 new frontend --directory frontend --routing --style=scss
cd frontend
npm install
npm start
```

If you prefer to use this scaffold directly, run `npm install` then `npm start` after installing `@angular/cli` globally.
